Android 7.0 or newer · 23 October 2026

  1. When your browser warns about the file, tap Download anyway. It warns about every app from outside a store.
  2. Open the file, then allow Install unknown apps for your browser when asked.
  3. Tap Install. If Play Protect asks, tap More details → Install anyway.

Good to know

  • Already have it from Google Play? You don't need this. The two can't be installed over each other: to switch, first save your collection (Settings → Back up & restore → Back up collection), uninstall, install this one, then use Restore from backup.
  • Without Google services everything works: the scanner, binders, prices and backups. Only the ad banner stays empty.
